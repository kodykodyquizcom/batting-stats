# 打撃成績アプリ

野球の打撃成績を記録・集計する、スマホ向けのWebアプリです。

## 進み具合

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 画面の見た目 | ✅ 完了 |
| 2 | データ保存の仕組み | ✅ 完了 |
| 3 | 試合の登録・一覧 | ✅ 完了 |
| 4 | 打席の入力 | ✅ 完了 |
| 5 | 成績の自動計算 | ✅ 完了 |
| 6 | バックアップ | ✅ 完了 |
| 7 | 公開（MVP完成） | ✅ 完了（v1.0.0） |

## パソコンで確認する方法

1. Finderで `batting-stats` フォルダを開く
2. `index.html` をダブルクリックすると、ブラウザでアプリが開く
3. スマホと同じ見た目で確認したいとき（Google Chromeの場合）
   - `option` + `command` + `I` を押して開発者ツールを開く
   - `command` + `shift` + `M` を押して、スマホ表示に切り替える
   - 画面上部の機種名から「iPhone 14 Pro」などを選ぶ

## データの保存について

- 保存先：この端末のブラウザ（localStorage、キー名 `batting-stats/db`）
- 画面のコードは `App.store` の関数だけを使ってデータを扱います。
  将来サーバーに保存するときは、`local-storage-adapter.js` と同じ形の部品を作って差し替えます。
- 削除したデータは「削除日時」を入れて残しています（将来の同期のため）。
- データが壊れていた場合は消さずに `batting-stats/db/broken-日時` という名前で残します。

## 成績の計算方法

計算は `js/stats.js`、結果ごとのルールは `js/constants.js` にあります。

| 項目 | 計算式 |
|---|---|
| 打数 | 打席 − 四球 − 死球 − 犠打 − 犠飛（失策・野選は打数に含む） |
| 打率 | 安打 ÷ 打数 |
| 出塁率 | (安打 ＋ 四球 ＋ 死球) ÷ (打数 ＋ 四球 ＋ 死球 ＋ 犠飛) |
| 長打率 | 塁打 ÷ 打数（単打1・二塁打2・三塁打3・本塁打4） |
| OPS | 出塁率 ＋ 長打率（四捨五入前の値を足す） |

- 率は小数第4位を四捨五入して3桁で表示します（例：.333、1.250）。
- 分母が0のとき（例：打数0）は「-」と表示します。
- 本塁打は打点0で記録すると自動で1打点になります。

## バックアップ

設定画面から使います。

| 機能 | 内容 |
|---|---|
| データを書き出す（JSON） | 全試合・全打席の記録を `batting-stats-backup-日付-時刻.json` に保存 |
| バックアップから復元 | JSONファイルを選ぶと、今のデータと復元後のデータを比べる確認画面が出る。「復元する」で置き換え |
| 復元を取り消して元に戻す | 復元する直前のデータに1回だけ戻せる |
| 成績をCSVで書き出す | 試合ごと（古い順）と通算の成績を `batting-stats-日付-時刻.csv` に保存。Excelで開ける。復元には使えない |

- おかしなファイル（このアプリのものではない、壊れている等）は、どこが悪いかを表示して読み込みません。今のデータは変わりません。

## スマホで使う（GitHub Pages・PWA）

- 公開先：`https://（GitHubのユーザー名）.github.io/batting-stats/`
- Google Pixel の Chrome で開き、メニュー「︙」→「ホーム画面に追加」（または「アプリをインストール」）でアプリのように使えます。
- 一度開けば、電波がない場所でも使えます。

### 公開し直すとき（アプリを修正したとき）

1. `sw.js` の `CACHE_VERSION` を変える（例：`'v1.0.0'` → `'v1.0.1'`）。変えないとスマホに古い画面が残ります。
2. 変更したファイルを GitHub にアップロードする。
3. 数分後にスマホでアプリを開くと「新しいバージョンがあります［更新］」と出るので、「更新」を押す。

### 注意：Macとスマホのデータは別々です

- 記録は「その端末のブラウザの中」に保存されます。Macとスマホのデータは自動では同期されません。
- Macで `index.html` を開いて入力したデータと、公開したアプリのデータも別々です。
- 端末間でデータを移すときは、設定画面の「データを書き出す（JSON）」→ ファイルを移す →「バックアップから復元」。
- 記録はスマホ1台で行い、Macはバックアップの保管場所にするのがおすすめです。

## 更新履歴

### v1.1.0（改良第1弾：試合管理）

- 試合に「試合区分（公式戦・練習試合・未設定）」と「球場」を登録できるようにした。
- 試合一覧の日付ラベル：公式戦はエンジ色、練習試合と未設定は従来の紺色。区分のラベルも表示。
- 球場は、登録済みの球場をタップして選ぶか、新しい名前を入力して追加できる（同じ名前は重複登録しない）。
- 試合詳細に試合区分と球場を表示。
- CSVに「試合区分」「球場」の列を追加。
- データ形式をバージョン2に更新。以前のデータ・バックアップは自動で変換して読み込む（以前の試合は「未設定」）。
  変換前のデータは `batting-stats/db/before-migration-v1` に元の形のまま退避する。
- 注意：v1.1.0で書き出したバックアップは、古いv1.0.0では読み込めない（エラーになり、データは壊れない）。

### v1.2.0（改良第2弾：打席入力・出場情報）

- 試合ごとの出場情報：出場区分（スタメン・途中出場・出場なし・未設定）、途中出場の形（代打・代走・守備）、打順（1〜9番）、守備位置（変更の履歴つき）。
- 打席入力パネル：普段は閉じておき、画面下の「＋ 第N打席を記録」で開く。下へスワイプ・×・外側のタップで閉じられ、中は縦にスクロールできる。
  安打・四死球・三振は結果ボタン1回で記録して閉じる。閉じても入力途中の内容は残る。
- 打球の詳細（アウト・犠打・犠飛・失策・野選）：打球の種類と処理した守備位置。「遊ゴロ」「中飛」「三直」のように表示。
- 打席の状況（任意）：イニング（1〜20回・表裏）、アウトカウント、走者状況。
- 打席の修正パネルで、保存していない変更があるときは閉じる前に確認する。
- CSVに「出場」「打順」「守備位置」の列を追加。
- データ形式をバージョン3に更新。以前のデータ・バックアップ（v1.0.0・v1.1.0）は自動で変換して読み込む（新しい項目は「未設定」）。
  変換前のデータは `batting-stats/db/before-migration-v2`（v1.0.0からの場合は `-v1`）に元の形のまま退避する。
- 注意：v1.2.0で書き出したバックアップは、古いv1.1.0以前では読み込めない（エラーになり、データは壊れない）。
